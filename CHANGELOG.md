# Foundry Stream Overlay Changelog

## v0.9.0 — Themed OBS Frames

- Added four simple 1920×1080 OBS frame themes: **Dark**, **Muted Light**, **Nature**, and **Bronze**.
- Added matching frame previews to the Foundry VTT OBS Layout editor.
- Theme selection now keeps the GM/PC cards and OBS border visually matched.
- Changed the Light theme to a softer muted gray/parchment palette instead of bright white.
- Added standalone SVG frame assets under `overlay/frames/`.
- OBS frame reaches the full canvas edges while GM and PC cards remain movable.
- Maintains Foundry VTT **14.368** compatibility.
- OBS continues to use `overlay/obs-overlay.html` as the main Browser Source.
