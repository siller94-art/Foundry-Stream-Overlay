# Standalone OBS Image Overlays

These assets are the standalone OBS Image Source versions of the existing Foundry Stream Overlay frame design. They do not require Foundry, a Browser Source, JavaScript, WebSocket, or a plugin connection.

The ZIP contains Dark, Muted Light, Nature, and Bronze 1920x1080 transparent PNG overlays. The larger-border versions use a 72 px bottom border to cover the normal Windows taskbar area, 28 px side borders, and a 24 px top border.

## OBS setup

1. Extract the ZIP.
2. In OBS choose Sources > + > Image.
3. Select the desired PNG.
4. Keep the image at 1920x1080.
5. Place the image source above Display Capture or Game Capture.
6. Lock the image source after positioning it.
